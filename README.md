# AppDesigner – strona produktu

Strona: **https://techniktomek.github.io/appdesigner-strona/**

- `index.html` – strona główna (funkcje, jak to działa, cennik, FAQ)
- `regulamin.html`, `zwroty.html`, `prywatnosc.html` – dokumenty wymagane przez Lemon Squeezy
- `site.js` – **ustawienia**: link do zakupu (`buyUrl`), kontakt (`contactUrl`), sprzedawca (`seller`)

Po zmianie plików wystarczy `git push` – GitHub Pages opublikuje stronę w 1–2 minuty.
